Tentang IPTEK HMTI

Departemen IPTEK berfokus pada pengembangan kemampuan teknikal mahasiswa di bidang software dan hardware melalui pelatihan berkala, workshop interaktif, dan kolaborasi proyek akademik maupun organisasi.

Bidang Keahlian

Departemen IPTEK

Mengenal dua divisi spesialisasi utama dalam Departemen IPTEK yang mendukung perkembangan technical skill mahasiswa Informatika.

Divisi 01

Departemen Software

Berfokus pada pengembangan aplikasi dan solusi berbasis perangkat lunak untuk mendukung kebutuhan akademik dan organisasi.

Daftar Kemampuan & Fokus:

Web Development
Application Dev
Programming
Software Solution
Divisi 02

Departemen Hardware

Berfokus pada perakitan, konfigurasi jaringan, troubleshooting, dan pengembangan sistem infrastruktur teknologi.

Daftar Kemampuan & Fokus:

Computer Assembly
Network Config
Troubleshooting
System Development
Program Kerja
